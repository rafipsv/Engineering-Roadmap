# Rafi 2-Year Engineering Roadmap v2

104 weeks. Saturday–Thursday study, Friday protected.

## v2 additions
- 50+ focused mini-projects and capstones.
- DSA/problem-solving practice layer.
- Every DSA topic: 5 Codeforces + 5 HackerRank + 5 LeetCode entries.
- Individual problem checkboxes.
- Project completion checkboxes.
- `data/curriculum.json` stores roadmap/project/problem content.
- `data/progress.json` is the intended source of truth for progress.
- Save/import progress JSON from the UI.

## Run
Use VS Code Live Server or any local HTTP server. The app fetches JSON files, so opening `index.html` directly with `file://` may be blocked by browser security.

## Progress workflow
1. Open the site.
2. Work through weeks/problems/projects.
3. Click **Save progress.json** periodically.
4. Keep that JSON with the project.
5. Use **Import progress.json** after moving machines or replacing the template file.
